## 📄 Описание файлов

### Основные файлы темы

#### `style.css`
**Назначение:** Главный файл стилей темы
- Содержит метаданные темы (название, автор, версия)
- Импорт шрифтов Google Fonts
- Все стили организованы по компонентам
- Каждый компонент в отдельной секции с комментариями
- Адаптивные медиа-запросы

**Структура:**
```css
/* 1. Метаданные темы */
/* 2. Импорт шрифтов */
/* 3. Базовые reset стили */
/* 4. КОМПОНЕНТ: HEADER */
/* 5. КОМПОНЕНТ: LAYOUT */
/* 6. КОМПОНЕНТ: PAGE */
/* 7. Утилиты */
/* 8. Адаптивность */
```

#### `functions.php`
**Назначение:** Функции и хуки WordPress
- Подключение стилей
- Регистрация меню
- Поддержка функций темы (миниатюры, HTML5)
- Настройка ширины контента

#### `header.php`
**Назначение:** Шаблон шапки сайта
- `<head>` с метатегами
- Вызов `wp_head()`
- HTML разметка header с классами `.galleryyachts-header*`
- Логотип с ссылкой на главную
- Статичное меню навигации
- Контактная информация

#### `header-with-menu.php`
**Назначение:** Альтернативная шапка с WordPress меню
- Аналогично header.php
- Использует `wp_nav_menu()` для динамического меню
- Fallback на статичное меню если WP меню не создано

#### `footer.php`
**Назначение:** Шаблон подвала
- Вызов `wp_footer()`
- Закрывающие теги `</body>` и `</html>`

#### `index.php`
**Назначение:** Главный шаблон (blog loop)
- Используется для списка записей
- Цикл WordPress (`while have_posts`)
- Классы `.galleryyachts-layout__main` и `.galleryyachts-page__content`

#### `page.php`
**Назначение:** Шаблон отдельных страниц
- Аналогично index.php, но для страниц
- Добавлен заголовок `.galleryyachts-page__title`

## 🎨 Система классов

### Префикс: `galleryyachts-`

Все классы компонентов используют префикс для предотвращения конфликтов.

### Формат (BEM-подобный):

```
.galleryyachts-[компонент]__[элемент]--[модификатор]
```

### Примеры:

| Класс | Описание |
|-------|----------|
| `.galleryyachts-header` | Компонент шапки |
| `.galleryyachts-header__logo` | Логотип в шапке |
| `.galleryyachts-header__logo-text` | Текст логотипа |
| `.galleryyachts-header__nav` | Навигация в шапке |
| `.galleryyachts-header__nav-item` | Элемент навигации |
| `.galleryyachts-btn` | Базовая кнопка |
| `.galleryyachts-btn--primary` | Первичная кнопка (модификатор) |
| `.galleryyachts-btn--large` | Большая кнопка (модификатор) |

### 1. Установка темы

## 📊 Быстрая справка

### Создание нового компонента:

```css
/* В style.css: */
/* ============================================
   КОМПОНЕНТ: НАЗВАНИЕ
   Префикс: .galleryyachts-название
   ============================================ */

.galleryyachts-название {
    /* Стили компонента */
}

.galleryyachts-название__элемент {
    /* Стили элемента */
}

.galleryyachts-название--модификатор {
    /* Вариант компонента */
}
```

```html
<!-- В HTML/PHP: -->
<div class="galleryyachts-название">
    <div class="galleryyachts-название__элемент">
        Контент
    </div>
</div>
```

### Создание нового шаблона страницы:

```php
<?php
/**
 * Template Name: Название шаблона
 */
get_header(); ?>

<!-- Ваш контент с компонентами -->

<?php get_footer(); ?>
```
