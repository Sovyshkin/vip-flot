# История изменений Галерея яхт Theme

## Версия 1.0.0 (2 марта 2026)

### ✨ Новые возможности
- Создана полноценная WordPress тема на основе Vue компонента AppHeader
- Реализована система именования классов с префиксом `galleryyachts-` для предотвращения конфликтов
- BEM-подобная методология организации CSS
- Полностью адаптивный дизайн (Desktop, Tablet, Mobile)
- Импорт Google Fonts (Bebas Neue, Manrope, Golos Text)

### 📁 Файлы темы
- `style.css` - Главный файл стилей с организацией по компонентам
- `functions.php` - Базовые функции WordPress
- `header.php` - Шапка сайта с точной копией из Vue
- `header-with-menu.php` - Альтернативная шапка с WP меню
- `footer.php` - Подвал сайта
- `index.php` - Главный шаблон
- `page.php` - Шаблон страниц
- `template-full-width.php` - Пример страницы с компонентами

### 📚 Документация
- `INDEX.md` - Навигация по файлам темы
- `README.md` - Полное руководство по теме
- `QUICK-START.md` - Быстрый старт для начинающих
- `CSS-NAMING-GUIDE.md` - Подробные правила CSS и именования
- `COMPONENT-TEMPLATES.php` - Готовые шаблоны компонентов

### 🎨 Компоненты
- **Header** - Шапка сайта
  - Логотип с ссылкой
  - Навигационное меню
  - Контактная информация
- **Layout** - Структура страницы
- **Page** - Компоненты страниц
- **Utilities** - Утилитарные классы

### 🔧 Технические особенности
- Префикс всех классов: `galleryyachts-`
- Структура: `.galleryyachts-[компонент]__[элемент]--[модификатор]`
- Организация CSS по секциям с комментариями
- Адаптивные медиа-запросы для всех компонентов
- Поддержка WordPress 5.0+
- Поддержка PHP 7.4+

### 📱 Адаптивность
- Desktop: 1024px+
- Tablet: 768px - 1024px
- Mobile: до 768px

### 🚀 Что дальше?
- Добавьте screenshot.png (см. SCREENSHOT-INFO.txt)
- Создавайте свои компоненты следуя CSS-NAMING-GUIDE.md
- Расширяйте функциональность темы
