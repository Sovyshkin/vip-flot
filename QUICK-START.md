# Быстрая настройка Галерея яхт

## Шаг 1: Настройка WordPress

1. **Установите WordPress** (если еще не установлен)
   
2. **Скопируйте тему в WordPress:**
   ```bash
   cp -r gallery-yachts-theme /path/to/wordpress/wp-content/themes/
   ```

3. **Активируйте тему:**
   - Войдите в админку WordPress
   - Перейдите: Внешний вид → Темы
   - Активируйте "Галерея яхт"

4. **Проверьте, что раздел "Заявки" появился** в меню админки

## Шаг 2: Настройка Vue приложения

1. **Перейдите в папку app:**
   ```bash
   cd app
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Создайте .env файл:**
   ```bash
   cp .env.example .env
   ```

4. **Измените API URL в .env:**
   ```env
   # Замените на ваш URL WordPress
   VUE_APP_API_URL=http://localhost/wordpress/wp-json/gallery-yachts/v1/booking
   ```

5. **Запустите dev-сервер:**
   ```bash
   npm run serve
   ```

6. **Откройте приложение:**
   ```
   http://localhost:8080
   ```

## Шаг 3: Тестирование

1. **Прокрутите страницу до формы бронирования**

2. **Заполните форму:**
   - Имя: Тестовый пользователь
   - Телефон: +7 (999) 123-45-67
   - Дата: любая будущая дата
   - ✓ Поставьте галочку согласия

3. **Нажмите "Забронировать"**

4. **Проверьте результат:**
   - Должно появиться зеленое сообщение "Заявка успешно отправлена"
   - Форма должна очиститься

5. **Проверьте админку WordPress:**
   - Перейдите в "Заявки"
   - Должна появиться новая заявка с данными

6. **Проверьте email:**
   - На почту администратора должно прийти письмо

## Возможные проблемы

### "Не удалось отправить заявку"

**Решение 1:** Проверьте URL в .env
```bash
# Убедитесь, что WordPress доступен
curl http://localhost/wordpress/wp-json/gallery-yachts/v1/booking
```

**Решение 2:** Проверьте CORS
- Откройте DevTools → Network
- Посмотрите на запрос к API
- Если ошибка CORS, добавьте ваш localhost в `functions.php`:
  ```php
  $allowed_origins = array(
      'http://localhost:8080', // Ваш порт
  );
  ```

### "404 Not Found" на API endpoint

**Решение:**
- Убедитесь, что тема активирована
- Пересохраните Permalinks: Настройки → Постоянные ссылки → Сохранить
- Проверьте, что в functions.php нет синтаксических ошибок PHP

### Email не приходят

**Решение:**
- Установите плагин WP Mail SMTP
- Настройте SMTP сервер
- Или проверяйте заявки прямо в админке

## Что дальше?

После успешного тестирования:

1. **Настройте продакшн WordPress** на сервере
2. **Обновите .env** с продакшн URL
3. **Соберите Vue:** `npm run build`
4. **Деплойте** файлы из `dist/` на хостинг
