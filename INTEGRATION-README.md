# VIP FLOT - Интеграция Vue + WordPress

## Структура проекта

```
vip-flot/
├── app/                    # Vue.js фронтенд
│   ├── src/
│   │   └── components/
│   │       └── RequestBook.vue  # Форма бронирования
│   └── .env               # Конфигурация API
└── vip-flot-theme/        # WordPress тема (бэкенд)
    └── functions.php      # API endpoints и админ-панель
```

## Настройка WordPress (Бэкенд)

### 1. Установка темы

1. Скопируйте папку `vip-flot-theme` в директорию тем WordPress:
   ```
   /wp-content/themes/vip-flot-theme
   ```

2. Активируйте тему в админ-панели WordPress:
   - Перейдите в `Внешний вид` → `Темы`
   - Активируйте тему "VIP FLOT"

### 2. Что добавлено в functions.php

- **Custom Post Type** `vip_flot_booking` для хранения заявок
- **REST API endpoint**: `/wp-json/vip-flot/v1/booking` (POST)
- **CORS настройки** для работы с localhost во время разработки
- **Админ-панель** для просмотра заявок
- **Email уведомления** администратору о новых заявках

### 3. Просмотр заявок

После активации темы в админ-панели WordPress появится новый раздел:
- **Заявки** (значок буфера обмена в меню)

В этом разделе отображаются все заявки со следующими данными:
- Имя клиента
- Телефон (кликабельная ссылка)
- Желаемая дата прогулки
- Дата создания заявки
- IP адрес отправителя

## Настройка Vue.js (Фронтенд)

### 1. Установка зависимостей

```bash
cd app
npm install
```

### 2. Конфигурация API

Создайте файл `.env` в папке `app/`:

```bash
cp .env.example .env
```

Откройте `.env` и укажите URL вашего WordPress:

**Для локальной разработки:**
```env
VUE_APP_API_URL=http://localhost/wordpress/wp-json/vip-flot/v1/booking
```

**Для продакшена:**
```env
VUE_APP_API_URL=https://yourdomain.com/wp-json/vip-flot/v1/booking
```

### 3. Запуск dev-сервера

```bash
npm run serve
```

Приложение будет доступно по адресу `http://localhost:8080`

### 4. Сборка для продакшена

```bash
npm run build
```

Скомпилированные файлы появятся в папке `dist/`

## Работа формы бронирования

### Поля формы

1. **Имя** (обязательное)
2. **Телефон** (обязательное, с автоформатированием)
3. **Дата прогулки** (опционально)
4. **Согласие на обработку данных** (обязательное)

### Валидация

- Все обязательные поля проверяются на клиенте
- Дополнительная валидация на сервере WordPress
- Телефон автоматически форматируется как `+7 (___) ___-__-__`

### Отправка данных

1. Пользователь заполняет форму
2. При нажатии "Забронировать" данные отправляются на WordPress API
3. WordPress создает заявку в базе данных
4. Администратор получает email уведомление
5. Пользователь видит сообщение об успехе/ошибке

## API Endpoint

### POST `/wp-json/vip-flot/v1/booking`

**Тело запроса (JSON):**
```json
{
  "name": "Иван Иванов",
  "phone": "+7 (999) 123-45-67",
  "date": "2026-06-15",
  "consent": true
}
```

**Успешный ответ:**
```json
{
  "success": true,
  "message": "Заявка успешно отправлена",
  "booking_id": 123
}
```

**Ответ с ошибкой:**
```json
{
  "code": "missing_fields",
  "message": "Имя и телефон обязательны",
  "data": {
    "status": 400
  }
}
```

## CORS настройки

В `functions.php` настроены разрешенные origins для разработки:
```php
$allowed_origins = array(
    'http://localhost:8080',
    'http://localhost:8081',
    'http://localhost:3000',
);
```

Для продакшена добавьте домен вашего фронтенда в этот массив.

## Email уведомления

При создании заявки автоматически отправляется email на адрес администратора WordPress (`admin_email`).

**Формат письма:**
```
Тема: Новая заявка на бронирование - VIP Flot

Новая заявка на бронирование:

Имя: Иван Иванов
Телефон: +7 (999) 123-45-67
Дата: 2026-06-15

Просмотреть: [ссылка на заявку в админке]
```

## Troubleshooting

### Ошибка CORS

Если видите ошибку CORS в консоли браузера:
1. Проверьте, что тема WordPress активирована
2. Убедитесь, что URL вашего dev-сервера добавлен в `$allowed_origins` в `functions.php`
3. Очистите кеш браузера

### Заявки не отправляются

1. Проверьте URL API в `.env`
2. Откройте Network tab в DevTools и проверьте запрос
3. Убедитесь, что WordPress доступен по указанному URL
4. Проверьте, что тема активирована

### Email не приходят

1. Проверьте настройки SMTP в WordPress
2. Установите плагин для настройки SMTP (например, WP Mail SMTP)
3. Проверьте папку Спам

## Deployment (Продакшен)

### Vue фронтенд

1. Обновите `.env` с продакшн URL
2. Соберите проект: `npm run build`
3. Загрузите содержимое `dist/` на хостинг

### WordPress тема

1. Загрузите папку `vip-flot-theme` на сервер в `/wp-content/themes/`
2. Активируйте тему
3. Обновите `$allowed_origins` в `functions.php` с доменом фронтенда

### HTTPS

Убедитесь, что оба приложения работают по HTTPS для безопасности данных пользователей.
